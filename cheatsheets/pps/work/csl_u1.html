4Selection: switch, case & break

switch (expr) requires integer/enum expression. case labels must be compile-time integer constant expressions. Duplicate cases are forbidden.

switch (op) {
  case '+': res = a + b; break;
  case '-': res = a - b; break;
  case '*': res = a * b; break;
  case '/': if (b) res = a / b; break;
  default:  res = 0; break;
}
Ex. Fall-through: Omitting break causes execution to flow directly into the next case. Used intentionally for grouping: case 'a': case 'A': count++; break;.

5Loops: while & do-while

while(cond): Entry-controlled (pre-test). Loop body executes 0 or more times.

do { body; } while(cond);: Exit-controlled (post-test). Executes at least 1 time. Note trailing semicolon.

/* Sum digits */               /* Menu prompt */
int n = 456, sum = 0;         int opt;
while (n > 0) {               do {
  sum += n % 10;  n /= 10;       scanf("%d", &opt);
}                             } while (opt < 1 || opt > 4);
Ex. Infinite loop idiom: while (1) { if (done) break; }.

6Arithmetic & Assignment Operators

Binary: +, -, *, /, %. Modulus % requires integer operands.

Division: 7 / 2 == 3 (truncates to zero). Float: 7.0 / 2 == 3.5
Modulus: -7 % 2 == -1; In C99+: (a / b) * b + (a % b) == a

Increment / Decrement: ++x (pre: increments first, yields new value); x++ (post: yields old value, then increments).

Ex. int i = 2; int a = ++i; /* a=3, i=3 */ int b = i++; /* b=3, i=4 */. Unsequenced operations like i = i++ or f(i++, i++) cause undefined behavior (UB).

7Explicit Type Casting

Syntax: (target_type)expression. Temporarily converts value representation.

int i = 7, j = 2;
double r1 = i / j;         /* 3.0 (integer division occurs first) */
double r2 = (double)i / j;  /* 3.5 (i promoted to double before div) */
int trunc = (int)3.999;     /* 3 (fraction truncated toward zero) */
Ex. Pointer casts: void *raw = malloc(n); int *arr = (int *)raw; (casting void* is optional in C, mandatory in C++).

9scanf & Input Buffer Control

scanf(format, &var, ...) reads formatted stdin. Returns count of successfully matched items, or EOF on end/error. Always pass memory addresses.

int n; double d; char s[20];
if (scanf("%d %lf %19s", &n, &d, s) == 3) { /* success */ }
Ex. Mandatory length for double: scanf("%lf", &d) (using %f writes only 4 bytes into 8-byte double). Clean trailing newline before reading char: scanf(" %c", &ch); (leading space skips whitespace).

12Bool & Fixed-Width Types

bool: Introduced as _Bool in C99. <stdbool.h> provides bool, true (1), false (0). C23 makes bool, true, false direct keywords.

Fixed-Width (<stdint.h>): Guaranteed exact widths across platforms:

int8_t, uint8_t, int16_t, uint16_t, int32_t, uint32_t, int64_t, uint64_t
intptr_t, uintptr_t (pointer-sized int), size_t (unsigned index)
Ex. Format macros in <inttypes.h>: uint32_t x = 42; printf("%" PRIu32 "\n", x); guarantees architecture-independent printing.

13Preprocessor: #define & Macros

Textual replacement performed before compilation. No types, no scope.

#define PI 3.1415926535
#define SQR(x) ((x) * (x))                /* enclose parameters in parens */
#define SWAP(a,b,T) do { T t = a; a = b; b = t; } while(0) /* multi-statement */
Ex. Stringify: #define STR(s) #s → STR(hello) → "hello".
Token-paste: #define CAT(a,b) a ## b → CAT(var, 1) → var1.

14Type Conversions: Implicit & Promotion

Integer Promotion: Types smaller than int (char, short, bool) are automatically promoted to int in arithmetic expressions.

Usual Arithmetic Conversions (Common Rank):

long double→double→float→unsigned long long→long long→unsigned long→long→unsigned int→int
Ex. Signed vs unsigned hazard: int a = -1; unsigned b = 1; if (a < b) evaluates to false because a promotes to unsigned (UINT_MAX). Always cast before comparing mixed signedness.

15Compound Blocks & Lexical Scope

A compound statement { ... } creates a local block scope. Identifiers have automatic storage duration by default (destroyed at closing brace }).

int x = 10;
{
  int x = 20;        /* shadows outer x */
  printf("%d ", x);  /* prints 20 */
}
printf("%d\n", x);  /* prints 10 */
Ex. Returning address of local stack variable (return &x;) leaves a dangling pointer and causes undefined behavior upon caller dereference.

16Iteration: for Loop Mechanics

Syntax: for (init; condition; update) body;. Execution order: init → condition → body → update → condition → ...

/* C99 scoped loop counter */
for (int i = 0; i < n; i++) { a[i] = i * 2; }
/* Multiple loop variables via comma operator */
for (int i = 0, j = n - 1; i < j; i++, j--) { int t = a[i]; a[i] = a[j]; a[j] = t; }
Ex. All expressions are optional: for (;;) creates a clean infinite loop identical to while (1).

18C Program Structure & Compilation

Order: Preprocessor directives → Global declarations → Function prototypes → main() → Function definitions. Execution begins at main.

Source (.c)→Preprocessor (cpp)→Compiler (cc1)→Assembler (as)→Linker (ld)→Executable (.exe)
#include <stdio.h>
#define SUCCESS 0
int add(int a, int b); /* prototype */
int main(void) {
  printf("Sum=%d\n", add(3, 4));
  return SUCCESS;
}
int add(int a, int b) { return a + b; }
Ex. main must return int. C99 allows omitting return 0; in main (implicitly returns 0). Other functions returning non-void must have an explicit return.

21Decision: if, else if & Ternary

Condition evaluates to scalar: 0 is false, any non-zero is true.

if (score >= 90) grade = 'A';
else if (score >= 75) grade = 'B';
else grade = 'F';

Dangling else rule: else binds to the nearest open if unless braced.

Ex. Ternary operator: int max = (a > b) ? a : b;. Ternary expressions return a value and can be embedded directly into function arguments: printf("%s", ok ? "PASS" : "FAIL");.
