2Storage Class: thread_local

Introduced in C11 as _Thread_local (and thread_local via <threads.h>; keyword in C23).

#include <threads.h>
thread_local int thread_specific_id = 0;
Ex. Each execution thread allocates an independent storage instance. Value changes in Thread A do not affect Thread B, preventing race conditions without mutex locking.

31D Arrays & Memory Layout

Contiguous block of homogeneous elements indexed 0 to N-1. Address formula: &a[i] = Base + i × sizeof(T).

int a[5] = {10, 20, 30}; /* a[3]=0, a[4]=0 */
int b[] = {1, 2, 3, 4};  /* size deduced as 4 */
size_t count = sizeof(b) / sizeof(b[0]); /* count = 4 */
Ex. C99 designated initializers: int arr[10] = {[0]=1, [5]=9, [9]=88}; fills specific indices; remaining elements are zeroed.

4Multi-Dimensional Arrays

2D array T arr[R][C] stores elements in row-major order: row 0, row 1, ..., row $R-1$. Contiguous in memory.

int m[2][3] = {{1, 2, 3}, {4, 5, 6}};
/* Offset formula: &m[i][j] = Base + (i * C + j) * sizeof(T) */
Ex. When passing 2D arrays to functions, the column dimension must be specified: void print_mat(int a[][3], int rows) or void print_mat(int (*a)[3], int rows).

5Binary Search Algorithm

Requires array to be strictly sorted. Compares key with middle element and halves the search space each step.

int binary_search(const int a[], int n, int key) {
  int low = 0, high = n - 1;
  while (low <= high) {
    int mid = low + (high - low) / 2; /* prevents overflow */
    if (a[mid] == key) return mid;
    else if (a[mid] < key) low = mid + 1;
    else high = mid - 1;
  }
  return -1;
}
Ex. Complexity: Best: $O(1)$, Worst/Avg: $O(\log_2 n)$. 1,000,000 items checked in $\le 20$ iterations. Iterative space: $O(1)$.

6Selection Sort Algorithm

Finds minimum element in unsorted subarray and swaps it to beginning of unsorted region. Exactly at most $n-1$ swaps.

void selection_sort(int a[], int n) {
  for (int i = 0; i < n - 1; i++) {
    int min_idx = i;
    for (int j = i + 1; j < n; j++) {
      if (a[j] < a[min_idx]) min_idx = j;
    }
    if (min_idx != i) {
      int t = a[i]; a[i] = a[min_idx]; a[min_idx] = t;
    }
  }
}
Ex. Complexity: $O(n^2)$ comparisons in all cases. Ideal when write operations to memory (e.g. Flash/EEPROM) are expensive. Unstable. In-place.

9Linear Search Algorithm

Sequentially scans array from index 0 to $n-1$. Works on unsorted data.

int linear_search(const int a[], int n, int key) {
  for (int i = 0; i < n; i++) {
    if (a[i] == key) return i; /* index found */
  }
  return -1; /* not found */
}
Ex. Complexity: Best case: $O(1)$ (found at index 0). Worst case: $O(n)$ (at index $n-1$ or absent). Average comparisons: $(n+1)/2 \sim O(n)$. Auxiliary space: $O(1)$.

10C Strings & Memory Layout

A C string is a 1D array of char terminated by the null character '' (ASCII value 0). "Hello" occupies 6 bytes.

char s1[] = "Hello";  /* Stack array: 6 bytes, modifiable */
char *s2  = "Hello";  /* Pointer to literal in .rodata: READ ONLY */
s1[0] = 'h';          /* OK: s1 becomes "hello" */
/* s2[0] = 'h'; → Segmentation Fault / Undefined Behavior */
Ex. sizeof(s1) == 6 (includes ''), whereas strlen(s1) == 5 (excludes '').

11String Tokenization: strtok

Splits string into tokens based on delimiter characters. Modifies the source string in place by inserting '' at delimiter locations.

char str[] = "apple,banana,orange";
char *tok = strtok(str, ",");
while (tok != NULL) {
  printf("Item: %s\n", tok);
  tok = strtok(NULL, ","); /* pass NULL on subsequent calls */
}
Ex. strtok maintains internal static state; it is not thread-safe and cannot be used on read-only string literals. Use POSIX strtok_r for multi-threaded code.

12Command-Line Arguments: argc & argv

Syntax: int main(int argc, char *argv[]). Transmits execution arguments from the OS shell to the program.

./program→argv[0] | arg1→argv[1] | arg2→argv[2] | NULL→argv[argc]
int main(int argc, char *argv[]) {
  if (argc < 2) { printf("Usage: %s <num>\n", argv[0]); return 1; }
  char *endptr;
  long val = strtol(argv[1], &endptr, 10);
  if (*endptr != '\0') { printf("Invalid numeric input!\n"); return 1; }
  printf("Parsed: %ld\n", val);
  return 0;
}
Ex. Prefer strtol over atoi because strtol validates non-numeric trailing garbage and detects integer overflow via errno == ERANGE.

13Storage Classes: static & extern

static (block scope): Retains value between function invocations. Initialized once at startup in BSS/Data segment.

static (file scope): Internal linkage. Limits visibility strictly to current .c translation unit.

extern: Declares a global variable/function defined in another file without creating storage.

/* file1.c */ int global_score = 100;  static int secret_key = 42;
/* file2.c */ extern int global_score; /* references file1.c */
Ex. Function call counter: void count(void) { static int c = 0; printf("%d ", ++c); } → prints 1, 2, 3 on successive calls.

14Array-Pointer Duality & Decay

In expressions, array names decay to a pointer to their first element (&a[0]). Pointer arithmetic scales by element byte size:

a[i] == *(a + i) == *(i + a) == i[a]

Ex. Three exceptions to array decay: operand of sizeof, operand of address-of &, and string literal in char array initialization.

15Insertion Sort Algorithm

Builds sorted array one element at a time by picking current key and shifting larger elements in sorted prefix rightward.

void insertion_sort(int a[], int n) {
  for (int i = 1; i < n; i++) {
    int key = a[i], j = i - 1;
    while (j >= 0 && a[j] > key) {
      a[j + 1] = a[j];
      j--;
    }
    a[j + 1] = key;
  }
}
Ex. Complexity: Best: $O(n)$ (already sorted), Worst/Avg: $O(n^2)$. Stable, in-place, adaptive. Preferred algorithm for small arrays ($n ≤ 16$).

18Functions: Prototypes & Definitions

Function anatomy: return_type name(param_list) { body }. Prototypes declare return and argument types to enable compiler validation before definition.

double power(double base, int exp); /* prototype */
int main(void) {
  printf("%.2f\n", power(2.5, 3));
  return 0;
}
double power(double base, int exp) {
  double res = 1.0;
  for (int i = 0; i < exp; i++) res *= base;
  return res;
}
Ex. void functions take no return expression (return; exits early). C23 mandates f() is identical to f(void).

19Parameter Passing: Value vs Address

C is strictly pass-by-value: arguments are copied onto stack frames. Modifying local parameter variables has zero effect on caller's variables.

Pass-by-Address (Emulated Reference): Pass pointer address &x; callee dereferences with *p to mutate caller memory directly.

void swap(int *a, int *b) {
  int temp = *a;  *a = *b;  *b = temp;
}
/* In caller */: int x = 5, y = 10; swap(&x, &y); /* x=10, y=5 */
Ex. Pointers also enable functions to return multiple results (e.g. void get_bounds(int *min, int *max)).

20Recursion & Stack Frame Mechanics

A recursive function calls itself. Requires: (1) Base case that terminates recursion; (2) Recursive step reducing problem towards base case.

long long fact(int n) {
  if (n <= 1) return 1;          /* Base case */
  return n * fact(n - 1);       /* Recursive call */
}
fact(3)→3 × fact(2)→2 × fact(1)→Base: 1→Unwind: 2 → 6
Ex. Each call allocates a stack activation record. Unbounded recursion causes stack overflow. Time: $O(n)$, Space: $O(n)$ stack frames.

21Bubble Sort Algorithm

Repeatedly steps through list, compares adjacent elements, and swaps them if out of order. Largest unsorted element bubbles to end on each pass.

void bubble_sort(int a[], int n) {
  for (int i = 0; i < n - 1; i++) {
    int swapped = 0;
    for (int j = 0; j < n - 1 - i; j++) {
      if (a[j] > a[j + 1]) {
        int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
        swapped = 1;
      }
    }
    if (!swapped) break; /* early exit optimization */
  }
}
Ex. Complexity: Best: $O(n)$ (with swapped flag), Worst/Avg: $O(n^2)$. Stable (equal elements retain order). In-place ($O(1)$ space).
